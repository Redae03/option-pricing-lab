∑ SURROGATE MODEL — APPRENTISSAGE SUPERVISÉ DU PRICING

X = (S₀, K, r, σ, T, type) → y = C_BS(S₀, K, r, σ, T)    [dataset]
f̂ : X → ŷ = f̂(S₀, K, r, σ, T)    [modèle appris : Random Forest ou MLP]
MAE = (1/n)·Σ|y_i − ŷ_i|    RMSE = √[(1/n)·Σ(y_i − ŷ_i)²]    R² = 1 − SS_res/SS_tot
Principe : On génère un dataset artificiel de N options avec des paramètres aléatoires (S₀, K, r, σ, T) et le prix exact Black-Scholes comme label. Un modèle supervisé apprend la fonction de pricing. Une fois entraîné, la prédiction est quasi-instantanée : O(1). C'est le concept de surrogate model en finance quantitative (Ludkovski, 2018).
